# Experiment outputs

These files were generated by train_models.py using seed 42.

- results.json: data audit, selected hyperparameters and held-out test metrics.
- *_cv.csv: all cross-validation candidates and fold scores.
- *_predictions.csv: actual labels, positive-class probabilities and predictions for 13,333 labelled test records, in original row order after removing the missing-label record.
